How to play

Taking the quiz

  1. Select Take the quiz to start. The 10 questions appear in a random order each time.
  2. Read the question and answer it. Some are multiple choice, some are true or false, and some ask you to type a surname.
  3. Select Next question to move on. The button stays off until you have answered.
  4. On the last question, select Submit quiz to see your results.

How you are scored

Each correct answer is worth one point, so the top score is 10. Typed answers are not case sensitive, and a surname alone is accepted.

Your results page shows your score and percentage. It also lists every question with your answer, the correct answer and a short explanation.

Playing again

Select Try again with new questions on the results page to restart with a fresh random order.
